## Project Description

The Library Management System is a full-stack web
application developed using the MERN stack.

It helps manage library books, student records,
book issuing, book returns, and overdue books.

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
- Mongoose

## Features

1. Dashboard Statistics
2. Book Management
3. Student Management
4. Issue Books
5. Return Books
6. Overdue Books Management

## Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Install backend dependencies:

cd server
npm install

Create server/.env with the required database
connection settings. Never commit this file.

Start the backend:

npm run dev

Install frontend dependencies:

cd ../client
npm install

Start the frontend:

npm run dev

## Environment Configuration

The backend requires a MongoDB connection string
and may use a PORT variable.

Refer to the project's server configuration for
the exact environment variable names.

## Project Status
